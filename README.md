# kittenChat-data

#### 介绍
ChatGLM微服务应用体系
对接微信公众号登录校验, 包含抽奖系统设计等等


## 特性

- 基于 GPT 的自然语言处理能力
- 微服务架构，支持灵活的服务部署
- RESTful API 接口，易于集成
- 支持多种语言的聊天交互
- 可扩展的用户管理和会话管理功能

## 技术栈

- 编程语言：Java 
- Web 框架：Spring Boot 
- 数据库：MySQL
- 消息队列：RabbitMQ 
- 容器化：Docker

## 安装与配置

### 环境要求

- Java 8+
- Docker
- 数据库服务（MySQL）
